Userscript examples for @connect denial

Header

  • @connect <host> — allowlist of hosts GM_xmlhttpRequest may talk to. For any other site (except the page's own origin), SourceMonkey asks first, in a prompt window, and keeps the answer for the script.
  • @connect * — wildcard. Allow all hosts.

Details

  • Three userscripts target this page. Each one auto-fires a single GM_xmlhttpRequest at http://127.0.0.1:1/ when it runs and records the outcome below. Port 1 is a closed loopback port — connections refuse fast, so the test is reliable offline.
  • no-connect — no @connect. Expected: SourceMonkey’s prompt; answered with Deny, was denied for this script.
  • connect-mismatch — @connect somewhere.else.example.org. Host doesn’t cover 127.0.0.1. Expected: the same prompt, and the same message on Deny.
  • connect-allowed — @connect 127.0.0.1. Policy allows the request through; the network call itself fails with connection-refused because nothing is listening on port 1. Expected: an onerror without the denial message.
  • The prompt and the denial happen in the service worker before any fetch is issued, so a denied request never leaves the browser.
