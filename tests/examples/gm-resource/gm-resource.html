Userscript examples for GM_getResource*

APIs

  • GM_getResourceText(name) — returns the body of an @resource as a UTF-8 string, or undefined when the name isn’t declared. Binary resources still come back — the bytes are decoded with replace-on-error rather than throwing.
  • GM_getResourceURL(name) — returns a blob: URL the page can fetch / embed (e.g. as an <img src>). The blob carries the Content-Type the resource was fetched with so the browser dispatches correctly. Tampermonkey returns a data: URL instead.

Details

  • Resources are prefetched at script load / refresh time and stored alongside the userscript — no runtime fetch happens when the userscript calls GM_getResource*.
  • This userscript declares three @resource entries pointing at sibling files in the example directory: a CSS, a JSON, and an SVG. Click the buttons to load each back via the GM API.
  • The same name in two different calls returns the same value — a blob URL is minted once per name and cached for the document’s lifetime.
  • An unknown name returns undefined from both APIs (null in Tampermonkey); the “missing” button demonstrates that.
