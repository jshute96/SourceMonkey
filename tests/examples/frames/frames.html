Userscript examples for iframes

Headers

  • A script runs in every frame whose own URL it matches. The top page doesn't have to match.
  • @noframes: runs in the top frame only.

Details

  • This page holds two frames: Frame A on the same origin, and Frame B on another origin (localhost and 127.0.0.1 swapped), with a nested frame inside it.
  • every-frame.user.js matches all four documents, and logs a row in each one it runs in. Its Count button increments a shared GM_setValue counter; every document shows it through GM_addValueChangeListener.
  • top-only.user.js matches all four too, with @noframes: it should log here only.
  • frame-b-only.user.js matches Frame B only, so it runs on this page without matching it.
  • Each script registers a menu command per document it runs in, named after the document. Running one logs a row in that document only.
  • every-frame.user.js also registers Every frame: mark all in each document. The menu shows it once, and running it logs a row in all of them.
