Userscript examples for a top-level 'use strict'

Each script reports whether it runs in strict mode:

  • page and content: one in each world, starting with 'use strict'; right after the metadata block. Both should be on.
  • strict-lib: no directive of its own, but its @require starts with one. Should be on.
  • own-after-lib: its own 'use strict' after a plain @require. Should be off, as in Tampermonkey and Violentmonkey.
