Userscript examples for GM_openInTab

APIs

  • GM_openInTab(url, options) — open url in a new tab. options is {active, insert, setParent}: active controls foreground/background; insert biases Chrome to place the new tab next to the opener; setParent closes the new tab when its opener tab closes.
  • GM_openInTab(url, loadInBackground) — legacy positional form. A truthy second arg means “open in background.”
  • Returns a control object: {close(), closed, onclose}. Assign a function to onclose to be notified when the user (or another script) closes the opened tab.

Details

  • Type any URL into the field below; the buttons open that URL with different call shapes. The page’s file:// origin can’t link out to http:// easily — if you opened this page directly off disk, prefer a file:// URL or open the index over HTTP first.
  • The log records each call’s returned control object and whether onclose has fired yet.
  • “Close last opened” calls .close() on the most recent return value.
