Userscript examples for @grant name casing

APIs

  • GM_log / GM.log
  • GM_xmlhttpRequest / GM.xmlHttpRequest
  • GM_getResourceURL / GM.getResourceUrl

Details

  • Every userscript on this page grants the same APIs, spelled with different capitalisation. Each one then reports which bindings actually landed in its scope.
  • canonical.user.js uses the spellings Tampermonkey and Violentmonkey document. It is the control: every probe should say function.
  • rewrite-case.user.js grants GM.xmlhttpRequest (lower-case h) and GM.getResourceURL (upper-case URL). These are the legacy names’ suffixes moved onto the GM. namespace; Violentmonkey resolves them by rewriting them back, and published scripts call them. SourceMonkey binds them alongside the GM4 spellings.
  • legacy-case.user.js grants GM_xmlHttpRequest (capital H), GM_Log, and GM_getResourceUrl. No manager binds these — every probe should read undefined. SourceMonkey additionally logs “did you mean…?” against each one.
  • Load this page under a different userscript manager with the same three scripts installed to see how that manager resolves the mis-cased names.
