Userscript examples for GM_cookie

APIs

  • GM_cookie.list(details, cb) — the cookies for a URL (this page’s by default), as cb(cookies, error).
  • GM_cookie.set(details, cb) / GM_cookie.delete(details, cb) — set or remove one cookie, as cb(error).
  • GM.cookie.list(details) (and .set / .delete) — the same, returning Promises.

Details

  • A script can only reach URLs its own @match / @include rules cover. The “another site” button asks about https://example.com/, which this script doesn’t match, so it fails.
  • httpOnly cookies are hidden from scripts by default.
  • GM_cookie.list and GM.cookie.list list the cookie named in the name field, or all of this page’s cookies when it’s empty. GM_cookie.list (all) always lists them all.
  • Each call adds one log line, newest first: the call, then what came back. After a set or delete it also shows document.cookie, the page’s own view, for comparison.
  • Open the page over http(s): browsers keep no cookies for file:// pages.
