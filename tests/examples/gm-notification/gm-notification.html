Userscript examples for GM_notification

APIs

  • GM_notification(details) or GM_notification(text, title?, image?, onclick?) — show an OS notification. Returns the new notification’s id (some managers wrap it in a Promise). Optional onclick and ondone callbacks fire when the user clicks or closes the notification.

Details

  • Buttons below fire GM_notification with different call shapes — details-object, positional, with a timeout, with callbacks, and a deliberately-invalid empty-text case.
  • In headless Chromium no desktop UI renders, but the round-trip still completes and the log records the resolved id. In a normal browser the desktop notification appears alongside.
  • Click / done callbacks log into this page’s log area when the manager dispatches them.
