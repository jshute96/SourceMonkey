Userscript examples for GM storage APIs

APIs

  • GM_setValue(key, value) — store a value under a per-script key.
  • GM_getValue(key, defaultValue?) — read a previously-stored value, returning defaultValue when the key is absent.
  • GM_deleteValue(key) — remove a stored key.
  • GM_listValues() — list every key this script has stored.

Details

  • Each API gets its own box. A preset button runs a canned call and fills that box’s form with the arguments it used, so the next call can be a small edit of one that worked. Hover a preset to see the exact call it makes.
  • Storage is scoped per userscript — this page can only see what this example script has written.
  • Values survive page reloads and, in SourceMonkey, service-worker restarts.
  • The value and defaultValue fields parse as JSON first (so you can store numbers, booleans, objects, arrays); text that doesn’t parse as JSON is stored verbatim.
  • An empty field means the argument is omitted. Leaving defaultValue blank calls GM_getValue(key) with one argument, which is a different question from asking for a default of "".
  • Fields marked (required) are documentation, not a gate — submit one blank and the call still happens, so the log shows what the API does about it.
