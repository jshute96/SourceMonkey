Userscript examples for GM_xmlhttpRequest

APIs

  • GM_xmlhttpRequest(details) — issue an HTTP request from the userscript’s privileged context (cross-origin allowed, gated by @connect rules in the script’s metadata). details is {method, url, headers?, data?, responseType?, timeout?, onload, onerror, ontimeout, onabort, ...}.
  • Returns a control object with .abort() so the caller can cancel an in-flight request.

Details

  • This example userscript declares @connect * so you can point it at any host. Managers prompt or warn differently for the wildcard — that’s part of what the example is showing.
  • Response types: text (default), json, blob, arraybuffer, document. Pick whichever matches what you’re fetching; the log records the runtime type so you can see how each manager presents binary payloads.
  • Requests carry your cookies for the target host by default, so a script can read a site as the signed-in you. Tick anonymous to send one without them.
  • Headers the browser forbids a script to set — Origin, Referer, Cookie, User-Agent, anything Sec-* — can be set here too. Point the URL at an echo service to see which ones a manager actually puts on the wire.
  • HTTP errors (4xx, 5xx) still fire onload with the status code — not onerror. Only network-level failures (DNS, refused connections) reach onerror.
