Userscript examples for DOM injection

APIs

  • GM_addStyle(css) — inject a <style> with the given CSS text into document.head. Returns the inserted <style> element so the userscript can remove or modify it later.
  • GM_addElement(tagName, attrs?) — create an element of tagName, copy attrs onto it (including a textContent key as inner text), and append it to the default parent.
  • GM_addElement(parent, tagName, attrs?) — same, but appended to the given parent element instead of the default.

Details

  • Default parent differs between managers. SourceMonkey always uses document.head (or document.documentElement if head doesn’t exist yet). Tampermonkey / Violentmonkey pick smarter defaults: head for script/link/style/meta, body for everything else. So in SM, the default-parent button puts a <p> in head where you can’t see it — check the log for what happened. Use the parent form button to write visibly into the playground.
  • USER_SCRIPT-world injection is exempt from page CSP, so these calls succeed even on pages that block inline scripts/styles.
  • Reset removes every element this userscript has injected so far (whether it went into head, body, or the playground), and restores the playground’s original contents.
