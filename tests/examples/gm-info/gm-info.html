APIs

  • GM_info — metadata object exposing the host userscript manager, the running script’s headers, and a few other bits. Available without an explicit @grant in most managers.

Details

  • Use case: compare GM_info across userscript managers. Install this script in several managers at once (SourceMonkey, Tampermonkey, Violentmonkey, …) and load this page; every running copy adds itself to the comparison table and the raw dumps below.
  • Each copy’s GM_info is printed verbatim as JSON, so you can see exactly what each manager populates.
  • Doubles as a sanity check that the userscript is running at all — if a dump appears, the script ran.
