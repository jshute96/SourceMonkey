Userscript examples for GM value-change listeners

APIs

  • GM_addValueChangeListener(name, callback) — register callback for changes to the per-script storage key name. Returns a listener id (any opaque value — pass it back to remove).
  • GM_removeValueChangeListener(id) — unregister the listener previously returned by add.
  • The callback receives (name, oldValue, newValue, remote). remote is true when the change came from another tab.

Details

  • The userscript registers two listeners on the demo-key entry at load. The form below sets that key — both listeners fire.
  • Open this page in two tabs to see cross-tab broadcasting: a write in tab A reaches tab B’s listener with remote=true while tab A’s own listener sees remote=false.
  • Use the remove listener 1 button to unregister the first listener; subsequent writes only fire listener 2.
