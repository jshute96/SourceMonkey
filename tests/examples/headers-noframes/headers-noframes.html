Userscript examples for @noframes

Header

  • No @noframes — the default. The script runs in the top-level document and in every sub-frame whose own URL matches. Each frame gets its own copy, with its own window and its own DOM.
  • @noframes — the script runs only in the top-level document, never in a frame.

Details

  • Matching is per frame: a sub-frame is checked against the @match / @include patterns using its own URL, not its parent’s. Both userscripts here match */headers-noframes/*.html, so the embedded frame below matches as well as this page.
  • The frame is a separate document, so it has its own #log list. A script that ran in both places writes one row up here and one row down there.
  • A frame with no URL of its own (about:blank, srcdoc) matches no pattern, so nothing is injected into it under SourceMonkey.
