Userscript examples

Interactive examples for SourceMonkey’s GM_* APIs, other granted APIs, and metadata headers. Each example pairs a static page.html with a script.user.js that drives it. Load this directory as a directory collection in SourceMonkey, or install individual *.user.js files in another userscript manager to compare behavior side-by-side.

  • GM_info — dump the metadata object every userscript receives.
  • GM_log — compare per-script console prefixes across managers.
  • GM storage — form-driven GM_setValue / GM_getValue / GM_deleteValue / GM_listValues.
  • GM value-change listeners — GM_addValueChangeListener / GM_removeValueChangeListener, including cross-tab broadcast.
  • GM_addStyle / GM_addElement — DOM injection helpers (CSP-exempt in USER_SCRIPT world).
  • GM_setClipboard — copy text to the system clipboard.
  • GM_xmlhttpRequest — cross-origin HTTP requests with selectable method, body, and response type.
  • GM_openInTab — open URLs in new tabs with the active / background / positional call shapes.
  • GM_notification — click-driven examples of every call shape.
  • GM_download — save files to the downloads folder from an http(s) URL, a data: URL, and a blob: URL, plus the refused cases.
  • GM_registerMenuCommand — add and remove entries in the toolbar icon’s right-click menu, surfaced indented under each script.
  • GM_getResourceText / GM_getResourceURL — read prefetched @resource files as text or as a blob: URL.
  • window.onurlchange — watch SPA navigations (pushState, replaceState, hash changes, back / forward) from page-driven buttons.
  • window.close / window.focus — close this tab and raise the browser window through the manager, where the page’s own calls are refused.
  • unsafeWindow — reading, calling, and writing the page’s own globals, plus the isolated-world case where it can’t work.
  • @run-at — one userscript per value (document-start / -end / -idle) running on the same page.
  • @inject-into — MAIN world (page) vs isolated USER_SCRIPT world (content), showing what each one can and can’t see of the page’s globals.
  • @require scope — a shared lib.js whose top-level class / const / function reach the script body, in both the MAIN and isolated worlds, without leaking onto the page’s globals.
  • @connect denial (negative cases) — scripts with no @connect, a mismatched host, and an explicit allow all firing GM_xmlhttpRequest at the same URL to show blocked-vs-allowed outcomes.
