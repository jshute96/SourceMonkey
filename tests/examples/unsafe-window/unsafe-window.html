Userscript examples for unsafeWindow

APIs

  • unsafeWindow — the page’s real window object, as opposed to whatever window the script’s own execution context gives it. Granted with // @grant unsafeWindow.

Details

  • The page defines window.__PAGE_APP__ in an inline <script>. Only code running in the page’s own JS realm can see it.
  • Chrome gives extensions two realms per document. In the isolated one (Chrome’s USER_SCRIPT world) the DOM is shared but window is a different object, and no synchronous bridge to the page’s realm exists — so unsafeWindow can only be real when the script runs in the page’s realm.
  • Managers therefore treat @grant unsafeWindow as a request for the page realm. In Chrome unsafeWindow === window there; on Firefox they differ (the manager hands out a wrapper).
  • isolated.user.js shows the opposite corner: @inject-into content pins the script to the isolated world, so its unsafeWindow is not the page’s and every page global reads as undefined.
