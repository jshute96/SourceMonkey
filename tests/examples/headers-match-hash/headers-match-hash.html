Userscript examples for #hash in URL matching

Headers

  • @match compares the scheme, host, path and query. It ignores the #hash, so a pattern that names one matches nothing.
  • @include and @exclude compare the whole URL, #hash included.

Details

  • Each variant that runs adds its rules to the log below. A hash change alone loads no new page, so the links with one reload.
    • Open headers-match-hash.html
    • Open headers-match-hash.html#part
    • Open headers-match-hash.html#other
  • Expected to run, by Chrome's rules:
    • With no hash: @match without the hash (both), @include without the hash, and the @exclude of #part.
    • With #part: @match without the hash (both), and @include with it.
    • With #other: @match without the hash (both), and the @exclude of #part.
  • Other managers:
    • Tampermonkey ignores the hash in all rules.
    • SourceMonkey, Violentmonkey and Chrome ignore the hash in @match but apply it in @include and @exclude.
  • SourceMonkey warns about an @match with a #, and doesn't run a script that has only those.
