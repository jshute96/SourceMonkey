Settings

Opening a .user.js link (or a .user.js file on this computer) shows SourceMonkey's install prompt instead of leaving it to Chrome, which just shows the file's source rather than offering to install it. On by default. Turn this off to get Chrome's stock behavior back, including for local files.

Logs per-navigation match lists and per-script update checks to the service-worker console. Off by default.

Search paths for local @require and @resource files (for scripts in local files)

Scripts loaded from a local file can also load resources from local files, overriding the original URL.
The script's local directory is searched first, then the collection directory it came from.
Then the directories here are searched, in order, looking for files matching any trailing part of the URL, site name included.
If not found locally, files are loaded from their original URL.

Note: Any files under these directories can be read by local userscripts.

    Downloads folder (for local copies of scripts)

    Local copy… on a script's page writes an editable copy into SourceMonkey/ under the browser's Downloads folder, and registers that folder as the Scripts copied in Downloads collection. Chrome doesn't tell extensions where Downloads is, so it is learned from the first copy. Correct it here if Chrome's download location has changed since.

    GitHub authentication

    Optional personal access token used when fetching from api.github.com and raw.githubusercontent.com. Lets you add private repos and lifts the GitHub API limit from 60 to 5000 requests per hour. Stored in chrome.storage.local on this machine; never sent to any non-GitHub host.

    How to create a token
    1. Open github.com/settings/personal-access-tokens and click Generate new token (fine-grained recommended).
    2. Repository access: pick the repos you want SourceMonkey to reach (or All repositories for convenience). For public repos you just want higher rate limits on, the default Public repositories selection is enough.
    3. Permissions → Repository → Contents: select Read-only. That's the only scope SourceMonkey uses; leave everything else at No access.
    4. Set an expiry, generate the token, and paste it above.

    Tip: revoke the token from the same settings page if you stop using SourceMonkey. Tokens never expire automatically unless you set an expiry.
