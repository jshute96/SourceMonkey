SourceMonkey

Settings

Logs per-navigation match lists and per-script update checks to the service-worker console. Off by default.

GitHub authentication

Optional personal access token used when fetching from api.github.com and raw.githubusercontent.com. Lets you add private repos and lifts the GitHub API limit from 60 to 5000 requests per hour. Stored in chrome.storage.local on this machine; never sent to any non-GitHub host.

How to create a token
  1. Open github.com/settings/personal-access-tokens and click Generate new token (fine-grained recommended).
  2. Repository access: pick the repos you want SourceMonkey to reach (or All repositories for convenience). For public repos you just want higher rate limits on, the default Public repositories selection is enough.
  3. Permissions → Repository → Contents: select Read-only. That's the only scope SourceMonkey uses; leave everything else at No access.
  4. Set an expiry, generate the token, and paste it above.

Tip: revoke the token from the same settings page if you stop using SourceMonkey. Tokens never expire automatically unless you set an expiry.
