Open a Greasy Fork form

This page opens a prefilled Greasy Fork form, which needs the prefill userscript. The script isn't running in this browser.

  1. Install a userscript manager, such as SourceMonkey or Tampermonkey, if this browser doesn't have one.
  2. Install or update the prefill userscript. If it's already installed, check that it's enabled.
  3. Reload this page to continue to the form.

Reloading keeps the form's values, which are stored in this page's URL.
