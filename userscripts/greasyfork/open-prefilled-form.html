Greasy Fork form-filler userscript

The SourceMonkey userscript manager includes tools for agentic userscript development, including a tool for publishing scripts to Greasy Fork. That uses a userscript that fills in the forms on Greasy Fork's script upload pages, so they can be opened from command-line tools.

Use the publish-on-GreasyFork skill or the greasyfork-url.py script to open prefilled Greasy Fork script upload forms through this page.

They're installed as part of SourceMonkey's development tools.

The userscript never clicks Submit on Greasy Fork. It opens tabs with the forms filled in, for you to review and submit.
