Userscript examples for GM storage APIs

APIs

  • GM_setValue(key, value): store a value under a per-script key.
  • GM_getValue(key, defaultValue?): read a previously-stored value, returning defaultValue when the key is absent.
  • GM_deleteValue(key): remove a stored key.
  • GM_listValues(): list every key this script has stored.
  • GM_setValues({key: value, ...}): store multiple values at once.
  • GM_getValues(keys | {key: default, ...}): given an array of keys, the ones that are set; given an object of defaults, every key, with its default when unset. With no argument, SourceMonkey and Tampermonkey return all values (Violentmonkey doesn't).
  • GM_deleteValues([key, ...]): remove multiple keys at once.
  • GM_addValueChangeListener(key, callback): here, a listener for each key the form uses, shown under Value changes.

Details

  • Storage is scoped per userscript: this page can only see what this example script has written.
  • Values survive page reloads and, in SourceMonkey, service-worker restarts.
  • The form parses the value field as JSON first (so you can store numbers, booleans, objects, arrays); plain text that doesn’t parse as JSON is stored verbatim.
