Userscript examples for dialog boxes

APIs

  • alert(message), confirm(message) and prompt(message, default) — the page’s JavaScript dialogs. Each stops the page until it’s answered.
  • beforeunload — a handler that cancels the event makes Chrome ask “Leave site?” before the page goes away.
  • input.click() on an <input type=file> — opens Chrome’s file chooser.
  • GM_xmlhttpRequest to a site the script’s @connect lines don’t name — the manager may ask whether to allow it.
  • showOpenFilePicker(), showSaveFilePicker() and showDirectoryPicker() — the File System Access pickers.

Details

  • Each button opens one kind of dialog box, and the log shows what the script got back.
  • The script runs in the manager’s own world where it has one, so the dialogs come from the script, not the page.
  • The script declares no @connect lines:
    • SourceMonkey asks in a window of its own.
    • Tampermonkey asks on a page of its own.
    • Violentmonkey doesn’t check @connect, so it sends the request without asking.
  • “Leave site?” needs a click on the page first, which Chrome requires before it asks. Check the box, then reload or close the tab.
  • Tampermonkey’s sandbox can’t call the pickers: they fail with “Illegal invocation”.
  • A file chooser that’s cancelled sends the input a cancel event, which the log shows.
  • Under sm-dev, use dialog show to see a waiting dialog and the commands that answer it. While sm-dev catches file choosers, Chrome refuses the pickers with an AbortError.
