Userscript examples for @connect

What @connect does

  • GM_xmlhttpRequest can send requests to other sites, which the page itself can’t.
  • A script’s @connect lines name the sites it may send to without asking:
    • @connect example.com: that site and its subdomains.
    • @connect *: any site.
    • @connect self: the sites the script runs on.
  • Requests to the page’s own site never need @connect.
  • For any other site, SourceMonkey opens a window asking whether to allow it. A denied request never leaves the browser.

The scripts

Three scripts run on this page. Each one adds a row of buttons below; a button sends a GET to that site and logs what happened.

Answering the prompt

  • Allow / Deny: for this site, from now on.
  • Allow once: sends this request; the next one asks again.
  • Cancel: blocks this request; the next one asks again.
  • Allow all sites: for every site, from now on, like @connect *.
  • The prompt allows setting persistent approval states. To reset, open the script’s page in SourceMonkey and click Reset on the sites listed in Network access.

Try it

The example sites need a network connection. Denied requests fail straight away without one.
