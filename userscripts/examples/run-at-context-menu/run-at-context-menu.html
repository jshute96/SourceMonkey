Userscript example for @run-at context-menu

What it means

  • The script matches this page like any other, but doesn't run when the page loads. It runs only when you ask, like a bookmarklet.
  • SourceMonkey lists it under Manual in the toolbar popup, with a Run this script command. Tampermonkey puts it in the page's right-click menu instead. Violentmonkey doesn't support it.
  • Each run adds a line below and registers its own menu commands. In SourceMonkey, a new run replaces the menu commands the last run registered.
