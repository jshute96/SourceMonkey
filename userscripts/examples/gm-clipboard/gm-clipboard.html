Userscript examples for GM_setClipboard

APIs

  • GM_setClipboard(text, info?) — copy text to the system clipboard. info accepts a MIME hint like "text/plain" or "text/html"; most managers honor it only on their offscreen/document-fallback paths.

Details

  • After clicking copy, paste somewhere (Ctrl+V) to verify the value made it through.
  • Some browsers / managers require focus or a recent user gesture for the underlying navigator.clipboard.writeText call. If the call rejects, the page log shows the error rather than failing silently.
  • SourceMonkey uses navigator.clipboard.writeText directly from the USER_SCRIPT world. Other managers may route through an offscreen document with execCommand('copy') as a fallback.
