Userscript examples for GM_ vs GM. return values

APIs

  • GM_setValue, GM_getValue, GM_listValues — storage.
  • GM_getResourceText, GM_getResourceURL — an @resource (resource.txt).
  • GM_addStyle, GM_addElement — DOM.
  • GM_log, GM_registerMenuCommand.
  • Each also in its GM. form (GM.getResourceUrl for GM_getResourceURL).

Details

  • The GM_ forms return their value directly.
  • The GM. forms come from Greasemonkey 4, where every one returns a Promise. Tampermonkey and SourceMonkey follow that for all of them.
  • Violentmonkey only does for some (storage, getResourceUrl). Its addStyle and addElement return the element with a then on it, which SourceMonkey also does, so await and direct use both work.
  • The table's columns: what the GM_ call returned, what the GM. call returned, and what awaiting the GM. result gave.
