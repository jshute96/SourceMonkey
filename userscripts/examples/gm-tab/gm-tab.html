Userscript examples for GM tab APIs

APIs

  • GM_getTab(callback) — this script’s object for the current tab, {} until something is saved.
  • GM_saveTab(tab, callback?) — saves that object for the current tab.
  • GM_getTabs(callback) — this script’s object for each open tab that has one, keyed by tab id.

Details

  • The load count is how many times this userscript has loaded in this tab. Each time it runs, it adds one to loads in the tab’s object and saves it.
    • Reloading this page counts up.
    • So does navigating to another page and coming back to this one in the same tab.
    • The object lasts for the lifetime of the tab. An ordinary page variable would read 1 every time.
  • Open this page in a second tab: it starts from 1, and GM_getTabs lists both tabs with their own counts.
  • Closing a tab drops its object, as does quitting the browser.
  • Tampermonkey only: Violentmonkey has no tab APIs.
