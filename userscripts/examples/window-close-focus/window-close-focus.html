Userscript examples for window.close / window.focus

APIs

  • @grant window.close — replaces window.close() for the userscript with one the manager performs. The page’s own call is refused by the browser for any tab the script didn’t open itself.
  • @grant window.focus — replaces window.focus() with one that selects this tab and raises its browser window, neither of which page code can do.
  • Both are void, synchronous calls that take no arguments.

Details

  • The status line reports whether each method the userscript sees is still the browser’s (checked by looking for [native code] in its source). Both should read “manager” when the grants took effect.
  • “Focus this tab” has nothing to show while you’re looking at it. Use “Focus in 3 seconds”, then switch to another tab (or another window, or minimize the browser) before the timer fires.
  • Raising the window is ultimately the OS window manager’s decision. Several Linux desktops answer a programmatic raise by flashing the taskbar entry instead; selecting the tab still works.
  • “Close this tab” closes this tab. That ends the page, so run it last.
  • The page’s own window.close / window.focus are untouched — the override only exists inside the userscript’s world.
