Userscript examples for GM_log

APIs

  • GM_log(...args) — write the args to the JavaScript console with the userscript manager’s per-script prefix. The format of the prefix varies between managers and is one of the most visible differences in this example.

Details

  • GM_log writes to the JavaScript console (DevTools, F12) — it does not write to the page. The log area below records what was sent so you can line it up with what shows up in the console.
  • Each manager picks a different prefix shape. Compare: SourceMonkey’s [SourceMonkey:<id>] vs Tampermonkey’s [<name>].
  • Args are stringified by the manager. Passing an object commonly shows up as the literal string [object Object], not a structured dump.
