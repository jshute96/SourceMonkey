Userscript examples for a @resource that doesn't load

Header

  • @resource with a URL that doesn't exist, read with GM_getResourceText and GM_getResourceURL, and their GM. forms.

Details

  • The script still runs in every manager, but what it gets differs:
    • SourceMonkey and Tampermonkey give an empty string.
    • Violentmonkey gives the URL, from both getters.
  • SourceMonkey warns in the script's Log when it loads the script, and logs an error when the script asks for the resource.
  • Tampermonkey logs a warning to the page's console on each call. Violentmonkey logs nothing.
  • Violentmonkey's install page won't install this script, since it requires every file to load. Other ways of adding it work.
