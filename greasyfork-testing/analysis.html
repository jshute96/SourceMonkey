Pattern shapes

Judged on the host and path only. Absolute patterns contain no wildcard; a prefix has one trailing *; an inner glob has a * before the end, so it can match in the middle of a URL.

A *:// scheme is excluded from this judgement — it is just the normal way to write "http or https" and would otherwise push every *://site.com/* into the inner-glob bucket. Scheme wildcards are counted separately below.
